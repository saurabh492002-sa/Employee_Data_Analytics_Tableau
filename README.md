# Employee Data Analytics Dashboard | Tableau

## Project Overview

This project focuses on employee data analytics using Tableau. It presents employee demographics, departmental distribution, salary analysis, hiring trends, background verification status, and IT asset allocation through an interactive dashboard.

The objective is to transform employee-related data into meaningful business insights that can support HR planning and workforce management.

## Project Objectives

- Analyze employee distribution by gender, city, and department.
- Track employee joining trends across different years.
- Identify the highest-paid employees.
- Analyze background verification status by company.
- Understand employee device allocation.
- Compare salary distribution across designations.
- Present key workforce metrics in an interactive dashboard.

## Tools and Technologies

- Tableau Public — Data visualization and dashboard development
- Microsoft Excel — Data source and preparation
- GitHub — Project documentation and portfolio hosting

## Dashboard Features

1. **Employee Summary:** Male and female employee counts and employee joining trends.
2. **Top 5 Highest-Paid Employees:** Comparison of employees with the highest recorded salaries.
3. **Gender Distribution by City:** Comparison of gender percentages across office locations.
4. **Employees by Department:** Department-wise employee distribution.
5. **Background Verification:** Analysis of verification status by previous company.
6. **Device Type Analysis:** Distribution of employee devices, such as laptops and desktops.
7. **Salary by Designation:** Comparison of salary totals across job designations.

## Dataset

The project uses employee-related data organized into the following categories:

- Employee Data
- Finance Data
- Background Verification
- Performance Metrics
- Attendance & Leave
- IT & Assets

## Key Business Questions

- How are employees distributed across departments and cities?
- What are the employee hiring trends?
- Which employees or designations have the highest recorded salaries?
- Which previous companies have the most verification failures?
- What is the distribution of employee device types?
- How can HR teams use these insights for workforce planning?

## Project Workflow

1. Understand the business requirements.
2. Inspect and prepare the source data.
3. Connect the data to Tableau.
4. Establish relationships between relevant tables using Employee_ID.
5. Create calculated fields and key performance indicators.
6. Build individual visualizations.
7. Assemble the dashboard and format the layout.
8. Validate the calculations and dashboard results.
9. Document the project and publish the portfolio.
